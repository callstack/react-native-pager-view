# Introduction

`PagerView` lets users swipe left and right (or up and down) through pages of content. It is a native component:

- on **Android** it renders a [Jetpack Compose pager](https://developer.android.com/develop/ui/compose/layouts/pager),
- on **iOS** it renders a [SwiftUI paged `TabView`](https://developer.apple.com/documentation/swiftui/tabview).
